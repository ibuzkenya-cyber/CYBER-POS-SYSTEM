IBUZKENYA POS - PHP + MySQL + XAMPP
====================================

INSTALLATION
1. Install XAMPP (Apache + MySQL).
2. Copy the "ibuzkenya_pos" folder into C:\xampp\htdocs\
3. Start Apache and MySQL in XAMPP.
4. Open http://localhost/phpmyadmin
5. Create/import database using database.sql.
   The SQL creates database `ibuzkenya_pos`.
6. Open http://localhost/ibuzkenya_pos/
