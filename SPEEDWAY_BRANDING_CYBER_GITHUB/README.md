# SPEEDWAY BRANDING CYBER POS

The standalone POS system for SPEEDWAY BRANDING CYBER, Gatitu Junction.

## Files
- `index.html` — the POS application, including invoices and receipts. The invoice phone number uses the same business phone setting as the receipt.
- `stock-list-template.csv` — a template for preparing a stock-list import, if you use that feature.

## Run on your computer
1. Download or extract this project folder.
2. Double-click `index.html` to open it in a modern browser such as Google Chrome or Microsoft Edge.
3. Use **Backup/Settings** to export backups regularly.

**Data note:** this version is a standalone browser app and stores its working data in that browser on that computer. Uploading the code to GitHub does not upload or synchronize sales records. Do not clear browser data without first exporting a backup. For multiple computers to share live records, a separate server/database setup is required.

## Upload this folder to GitHub
1. Sign in at https://github.com and create a new repository (for example, `speedway-branding-cyber-pos`).
2. Extract the ZIP so you can see this folder's files.
3. In the new repository, choose **Add file → Upload files**.
4. Upload `index.html`, `README.md`, `stock-list-template.csv`, and `.nojekyll` from this folder. You can also upload the files by dragging them into the upload area.
5. Commit the upload.

## Optional: publish as a website with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish and open the URL shown on that page.

The published site exposes the application code publicly if the repository is public. Do not store passwords, private customer data, API keys, or live sales backups in a public repository.
